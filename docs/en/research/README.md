# Research

What the `researcher` left in writing. One file per subject, with the date at the top.

This is not product documentation: it is what was known on a given day, with the address it came
from. When a piece of research becomes a decision, the decision goes into `docs/en/DECISIONS.md` —
and this file stays here, as the trail of why the decision was that one.

Rules that apply to every file in this folder:

- **Absolute dates.** “On August 26, 2026,” never “recently.”
- **Three separate piles:** what is verified (and how), what the source claims without checking,
  and what is the writer's assumption.
- **An interested source is flagged.** A manufacturer's page about its own product is data, not a
  verdict.
- **Chemistry is not researched here; it is calculated.** Formula, mass, TPSA, aromaticity, and
  configuration come from running RDKit. Research is for learning what the world calls things,
  not for saying how much they come to.
