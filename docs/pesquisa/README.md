# Pesquisa

O que o `researcher` deixou por escrito. Um arquivo por assunto, com a data no topo.

Isto não é documentação do produto: é o que se sabia num dia, com o endereço de onde veio. Quando
uma pesquisa vira decisão, a decisão vai para `docs/DECISOES.md` — e este arquivo continua aqui,
como o rastro de por que a decisão foi aquela.

Regra que vale para todo arquivo desta pasta:

- **Data absoluta.** "Em 26 de agosto de 2026", nunca "recentemente".
- **Três montes separados:** o que está verificado (e como), o que a fonte afirma sem conferência,
  e o que é suposição de quem escreveu.
- **Fonte interessada se marca.** Página de fabricante falando do próprio produto é dado, não
  veredito.
- **Química não se pesquisa aqui, se calcula.** Fórmula, massa, TPSA, aromaticidade e configuração
  vêm do RDKit rodando. Pesquisa serve para saber como o mundo chama as coisas, não para dizer
  quanto dá.
