# Divulgação

O que o Rotamer diz de si mesmo em público. Um arquivo por peça, com a data no nome —
`2026-08-27-convite-professores.md`.

Isto não é material de apoio: é **promessa registrada**. Um dia um professor vai cobrar o que
leu aqui, e o produto precisa poder responder.

Regras que valem para todo arquivo desta pasta:

- **Só se afirma o que o produto faz hoje.** A seção "Nunca afirme" do `CLAUDE.md` é lei: nada de
  previsão de reação, nada de atividade biológica, nada de substituir ChemDraw, PyMOL ou Maestro,
  e nada de "nomeia molécula" — ele deixa batizar, que é outra coisa (D-15).
- **Número sem medição não entra.** Nem usuário, nem escola, nem desempenho.
- **Depoimento é de gente real, ou não existe.** Não se escreve exemplo com nome inventado.
- **Captura de tela é afirmação.** Os números ao lado da molécula têm que ser os que o produto
  calcula para aquela molécula.
- **`[?]` marca o que ainda não foi conferido**, e texto com `[?]` não vai para o ar.
- Quando a peça for publicada, anote onde e quando, no próprio arquivo.
